# 校正の手順

CurrFuel の残量は、次の3つで決まります。順番に合わせていくと、ずれの原因を切り分けやすくなります。

| 項目 | 効くところ | 合わせる場所 |
|---|---|---|
| パック電圧 | 開始時の残量 | センサーの Offset / Ratio |
| 電流 | 飛行中の減り方 | `CurrGain` |
| 負荷の違い | フライトの内容による減り方の違い | `RateGain` / `RefRate` |
| 容量 | 減り方と開始オフセットの大きさ | `Capacity` |

## 1. パック電圧を合わせる

開始時の残量は、無負荷のパック電圧から決まります。電圧センサーがずれていると、開始時の%がずれます。

1. 満充電に近いパックを、機体につなぎます(モーターは回さない)。
2. 信頼できる電圧計(充電器の表示でも可)で、パック電圧を測ります。
3. 送信機のテレメトリー画面で、`VoltSrc` に使っているセンサーの値を確認します。
4. ずれがあれば、センサーの **Offset / Ratio** で合わせます(モデル設定 → テレメトリー → センサーを選んで Edit)。小数の Offset を入れるときは、Precision を `0.00` にします。

## 2. `Capacity` を決める

- **パックの実容量に近い値**を入れてください(例: 5000mAh のパックなら 5000)。
- 開始時の残量は `(100 − 開始電圧から求めた%) × Capacity ÷ 100` を、消費済みとして加算します。`Capacity` を実容量より小さくすると、その分、開始時の消費量が小さく見積もられます。
- 「80% までしか使わない」のような運用は、`Capacity` を小さくするのではなく、音声警告やロジカルスイッチの閾値(例: cBAT が 20% 以下)で行うと、わかりやすくなります。

## 3. `CurrGain` を合わせる

ESC の電流センサーは、機種によって倍率の誤差があります。充電器に入った容量と比べて、補正します。

### 手順

1. パックを**満充電**にします。
2. 送信機の電源を入れて(または `ResetSw` で)、積算を 0 から始めます。
3. 1〜数フライト飛ばします。電源を入れ直さずに続けて飛ばす場合は、**機体のパックを同じまま**にして、ResetSw を使わないでください。
4. 着陸後、**機体の電源を外す前に**、画面の括弧内のmAh(消費容量)を控えます。
5. パックを充電器につなぎ、充電された容量(mAh)を控えます。
6. 次の式で、新しい `CurrGain` を求めます。

```
新しい CurrGain = 今の CurrGain × 充電量(mAh) ÷ CurrFuel の消費容量(mAh)
```

7. `CurrGain` を設定して、次のフライトで確認します。

### 例

`CurrGain` が 100 で、CurrFuel の消費容量が 3800mAh、充電器の充電量が 4200mAh だった場合:

```
100 × 4200 ÷ 3800 = 110.5  →  CurrGain を 111 に
```

### コツ

- **3〜5回のフライトの平均**で合わせると、安定します。
- 充電器の表示は、充電効率などの影響で、実際の放電量とわずかにずれることがあります。数%のずれは、気にしすぎなくて構いません。
- 括弧内のmAhは、開始電圧のオフセットを含まない**積分値だけ**です。満充電から始めたフライトでは、そのまま充電量と比べられます。満充電でないパックで比べる場合は、飛ばす前に使った分は含まれない点に注意してください。
- ホバリング中心のフライトと、激しい演技のフライトで、比率が違う場合があります。普段のフライトの内容で合わせてください。
- ESC、パック、機体を変えたときは、取り直してください。

## 4. 放電レートによる補正(`RateGain` / `RefRate`)(任意)

ホバリング中心のフライトと、演技中心のフライトで、ずれ方が違う場合の補正です。電流を**放電レート(Cレート)**で見て、基準から離れるほど、電流の倍率を変えます。

```
C(放電レート) = 電流[A] ÷ (Capacity[mAh] ÷ 1000)       例: 5000mAh のパックで 50A = 10C
```

| オプション | 意味 |
|---|---|
| `RefRate` | 基準の放電レート(0.1C 単位。100 = 10.0C)。**普段のフライトの平均レート**に合わせます |
| `CurrGain` | 基準レート付近のフライトでの倍率。手順3のとおりに合わせます |
| `RateGain` | 基準から 10C 離れるごとの、倍率の変化(%)。0 なら補正なし |

### `RefRate` の決め方

- 3Dで 3〜4分飛ばして、終了時の残量が 50〜35% なら、平均は約 10C です。→ `RefRate` = 100
- ホバリング練習が中心なら、5C 前後です。→ `RefRate` = 50

迷ったら、いつものフライトの「消費容量 ÷ (飛行時間[時間] × Capacity)」を、平均Cレートの目安にしてください。

### 手順

1. `RateGain` を 0 にして、基準レート付近のフライトで、`CurrGain` を合わせます(手順3)。
2. 基準から離れたフライト(例: 基準が 10C で、ホバリング中心のフライト)を数回飛ばして、次の2つを求めます。
   - 比率 r = 充電量 ÷ CurrFuel の消費容量
   - そのフライトの平均レート Ch = CurrFuel の消費容量[mAh] ÷ (飛行時間[時間] × Capacity[mAh])
3. 次の式で、`RateGain` を求めます(Ref は基準レート[C]、例: 10)。

```
RateGain = (r − 1) × 100 ÷ ((Ch − Ref) ÷ 10)
```

4. `RateGain` を設定したら、基準レート付近のフライトで、`CurrGain` をもう一度確認します。

### 例

基準が 10C で、ホバリング中心のフライトの平均が 3C、比率 r が 1.07(CurrFuel が7%少なく出る)だった場合:

```
RateGain = (1.07 − 1) × 100 ÷ ((3 − 10) ÷ 10) = 7 ÷ (−0.7) = −10
```

`RateGain` を −10 にすると、3C のとき、倍率が 1 + (−0.10) × (−0.7) = 1.07 になります。

### 注意

- 倍率は、`CurrGain` の 0.5〜2 倍の範囲に制限されます。
- 符号は実測で決まります。高いレートほど多く消費する場合は、`RateGain` は正になります。
- 倍率が電流に応じて動くので、電流の変動が大きいフライトでは、積算の合計がわずかに変わります。手順4の確認は、そのためです。

## 5. 確認

校正が済んだら、次を確認します。

- [ ] 満充電のパックで電源を入れたとき、開始時の%が 100% 付近になる
- [ ] フライト後の消費容量が、充電量とほぼ一致する
- [ ] 着陸後、パックを外しても、最後の値が表示されたままになる
- [ ] Discover new sensors で `cBAT` が追加され、値が動く

## ずれたときの切り分け

| 症状 | 考えられる原因 |
|---|---|
| 満充電なのに開始時の%が低い | パック電圧センサーのずれ / 電圧が落ち着く前だった / セル数の誤判定(`Cells` を指定) |
| 消費容量が、充電量より常に多い・少ない | `CurrGain` が合っていない |
| フライトによって、ずれ方が変わる | 負荷の違い(ホバリング中心か、激しい演技か)/ ESC の電流センサーの特性 → `RateGain` で補正 |
| 0% のまま動かない | `VoltSrc` が未設定、または電圧が届いていない |
| 消費容量が増えない | `CurrSrc` が未設定、または Curr が 0 のまま |
